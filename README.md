# Bani K.H. Abdurrozaq

Situs statis (HTML + CSS). Siap di-deploy ke Vercel tanpa konfigurasi build.

## Deploy ke Vercel
1. Push folder ini ke repository GitHub, lalu import di vercel.com/new, atau
2. Jalankan `npx vercel` di dalam folder ini.
Framework Preset: "Other". Build Command & Output Directory dikosongkan.
